# ADR-026: Режимы контекста саб-агента

> **Статус:** ✅ Реализовано
> **Источник:** перенесено из AGENTS.md; приведено к as-built

**Решение:** при запуске саб-агента инструментом `task` родитель выбирает, какой контекст получит дочерняя сессия. Режим задаётся **параметром инструмента** `context_mode` (не CLI-флагом) и имеет четыре значения: `none`, `inherit`, `summary`, `last_n`.

**Контекст:** fork-модель Claude Code (саб-агент наследует всю историю родителя) удобна на коротких диалогах, но на длинных передаёт 50K+ токенов мусора. Изоляция OpenCode (агент — чистый лист, только prompt) дешевле, но легко упустить важный контекст. Synth даёт выбор.

**Режимы (as-built):**

| Режим | Поведение | Токены | Когда использовать |
|---|---|---|---|
| `none` | Саб-агент получает только prompt. Никакого контекста родителя | Минимальное | Самодостаточные задачи, параллельные workers, чистое выполнение по спецификации. **Фактический дефолт** |
| `inherit` | Саб-агент получает полную историю родительской сессии + свой prompt | Много (fork-модель) | Короткие диалоги (<10K токенов), продолжение разговора, тесная связь с родителем |
| `summary` | Контекст сжимается через отдельную LLM перед отправкой саб-агенту: ключевые решения, соглашения, результаты предыдущих шагов | Среднее (авто-саммари) | Длинные диалоги, нужно сохранить суть без мусора |
| `last_n` | Саб-агент получает последние N сообщений родителя (параметр `context_count`, по умолчанию 4) | Среднее | Длинные диалоги, важна свежая часть истории и не нужен весь лог |

**Отклонения от исторического текста AD:**
- **4 режима, а не 3** — добавлен `last_n`.
- **Дефолт — `none`** (в исходном AD значилось «`summary` — дефолт для продакшена»; в коде дефолт фактически `none`).
- **CLI `synth task --context` отсутствует** — режим задаётся параметром `context_mode` инструмента `task`; отдельной CLI-команды `task` нет.
- Если `contextOptimizer` недоступен (или не сконфигурирован), `summary` деградирует до `none` (`effectiveMode`).

**Реализация (as-built):**

| Компонент | Файл | Назначение |
|---|---|---|
| `ContextMode` / схема `task` | `packages/core/src/engine/tools/task.ts` | `type ContextMode = 'none' \| 'inherit' \| 'summary' \| 'last_n'`; `context_mode` — enum-параметр, `context_count` — размер `last_n` |
| Дефолт | `packages/core/src/engine/tools/task.ts` | `const contextMode: ContextMode = params.context_mode \|\| 'none'` |
| `last_n` | `packages/core/src/engine/tools/task.ts` | fork с `messageIndex = max(0, messages.length - contextCount)`, `DEFAULT_LAST_N = 4` |
| `summary` | `packages/core/src/engine/context/optimizer.ts` | `ContextOptimizer.summarize(session)` — вызов LLM; результат кешируется (`_summaryCache`, ключ `sessionId:indices` + хэш содержимого) |

**Связь:** ADR-025/ADR-028 (режимы сессии), ADR-033 (ветвление сессий), ADR-039 (план/todo в контексте).
