## 0.10.1 (2026-10-15)

Инженерный релиз без новых подсистем: **декомпозиция god-объектов** (ADR-095), разделение
архитектурных документов на **ADR и PROP**, конфигурация `num_ctx` через Synth, нативный
`/api/chat` для Ollama и серия **security-фиксов** (P0/P1/P2). 52 коммита после v0.10.0.

### Декомпозиция god-объектов (ADR-095)

- Принят паттерн **«вынос по швам»**: фасад сохраняет публичный API, связные блоки выносятся
  в модули, методы делегируют; один шов — один коммит, каждый шаг под зелёными `typecheck`/`lint`/`test`.
- Шаг 1 — `ui/lib/api/synthApi.ts`: 2 596 → 161 строки (32 доменных модуля `lib/api/*` + barrel,
  дословный перенос 223 методов, контрактный тест состава).
- Шаг 2 — `shared/types/index.ts`: 1 452 → 51 (12 модулей `types/*` + barrel; публичные экспорты
  `@itphx/synth-shared` идентичны, 531/531).
- Шаг 3 — `ui/components/panels/LeftPanel.tsx`: 2 230 → 59 (подкомпоненты и хуки `left-panel/*`).
- Шаг 4 — `core/server/app.ts` 2 014 → 380 и `backend/app.ts` 1 738 → 286 (модули `app/*`,
  порядок монтирования роутов сохранён побайтово).
- Шаг 5 — `core/engine/tools/task.ts`: 1 926 → 29 (7 модулей `engine/tools/task/*`, экспорты 1:1).
- Шаг 6 — `core/engine/orchestrator.ts`: 5 393 → 3 777 (9 модулей `orchestrator/*` + `phases/*`,
  `_processMessage` 1 668 → ~980 строк).
- Поведение не менялось: полный прогон (~5 084 теста) зелёный, каждый шаг — отдельный коммит с
  обновлением пакетных `AGENTS.md` и roadmap. Остаток 6b-2 (тело цикла Tool Use) отложен осознанно.

### Архитектурные решения: разделение ADR и PROP

- Каталог разделён на **ADR** — принятые решения (43) и **PROP** — предложения со сроком (41:
  32 actionable + 9 vision); файлы `adr-NNN-*.md` / `prop-NNN-*.md`, id и ссылки обновлены по репозиторию.
- Правила ведения — новый `docs/ARCH_DECISIONS.md`: пять классов документов, «default — документа нет»,
  ADR не длиннее страницы, блок «История»; индекс предложений и сроки — `docs/roadmap.md`.
- Автопроверка `scripts/adr-check.mjs` (`pnpm adr:check`/`pnpm adr:write`) собирает индекс ADR/PROP и
  проверяется в отдельном docs-workflow.
- Объёмные исторические ADR сжаты до одной страницы, as-built-часть вынесена в spec-дома:
  ADR-052 (415→60), ADR-046 (652→54), ADR-069 (608→59), ADR-070 (717→72), ADR-089 (601→49).
- Новые предложения: PROP-091 (бэкап/восстановление/перенос), PROP-092 (обслуживание инстанса),
  PROP-093 (версионирование доков), PROP-094 (наблюдаемость и метрики), PROP-096 (фоновые сессии
  саб-агентов), PROP-097 (фоновые процессы), ADR-104 (steering), PROP-099 (оптимизация памяти).
- Roadmap: секция «Приоритетные цели релиза 0.11» — PostgreSQL (+ оценка YDB), эксплуатация и ops-скиллы,
  оптимизация памяти.

### Провайдеры и модель контекста

- `num_ctx` теперь задаётся через Synth: поле `ProviderConfig.numCtx` (API `POST/PATCH /providers`,
  CLI `synth config provider add --num-ctx`, env `SYNTH_PROVIDER_<NAME>_NUM_CTX`) и **приоритетнее**
  `contextWindow` модели.
- Тип провайдера **ollama** переведён на **нативный `/api/chat`**: URL с `/v1` нормализуется
  (суффикс снимается с предупреждением), т.к. OpenAI-совместимый слой игнорирует `options`/`num_ctx`.
- README/compose/LLM_PROVIDERS и портал актуализированы: рекомендуемая локальная модель `qwen3.8:27b`,
  пояснение про эффективное окно и `OLLAMA_CONTEXT_LENGTH`.

### Безопасность

- **P0:** авторизация WS `send_message`/`permission_reply`/`permission_hold`/`cancel` по видимости сессии;
  `/api/v2/fs/*` — `authorizeProject` (read/write раздельно); backend-роуты сессий (export/notes/
  optimization/debug-system-message) — под `canAccessSession`.
- **P1:** fail-closed для внешних путей (`external_directory`: `ask`, в plan/strict — `deny`);
  `{dataDir}/secrets` и `{dataDir}/security` — в denied-префиксах; shell-guard fail-closed для
  `$VAR`/glob/`$()` и резолв `$SYNTH_DATA_DIR`.
- **P1:** OIDC `issuer`/`audience`, CORS fail-closed (открытый CORS только `SYNTH_CORS_ALLOW_ALL=true`),
  cookie `Secure` по умолчанию, containment аватара по `username`, rate limit на `POST /me/identities/claim`.
- **P2:** SSRF-политика `web_fetch` (private/loopback/link-local) с ручными редиректами (≤5 хопов);
  `docker-compose`: `SYNTH_API_KEY` берётся из `.env`, без хардкода.
- gitleaks allowlist для подтверждённых false positives.

### Надёжность и исправления

- **FileMutex:** захват подтверждается `mkdir` — гонка `ENOENT` между `mkdir` и `stat` больше не даёт
  «лок без владения» (теряемые обновления `ScheduleStore`/`FileLeader`); добавлена детерминированная регрессия.
- Терминальная ошибка LLM персистится в сессию (`metadata.status=error`) и не попадает в LLM-контекст.
- API провайдеров: алиасы `url`/`model`/`apiKey`, валидация `base_url`, поддержка `PATCH`.
- Стабилизированы флейки: `task-resume` (свежее чтение сессии вместо снапшота), `webhooks/service`
  (`drain()` вместо `setTimeout`), UI `SchedulerTab`/`EventsAdminSettings` (`waitFor`/flush вместо пустых `act`-пауз).
