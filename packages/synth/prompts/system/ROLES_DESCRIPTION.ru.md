# Роли ассистентов

Доступны следующие роли:

| ID | Название | Описание |
|----|----------|---------|
| assistant | Ассистент | Универсальный ассистент для общих задач |
| developer | Разработчик | Помощь с кодом, архитектурой, ревью |
| devops | DevOps Инженер | Инфраструктура, деплой, CI/CD |
| analyst | Аналитик | Исследования, документация, анализ |
| admin | Администратор | Системное администрирование |
| qa | QA Инженер | Тестирование, контроль качества |
| pm | Проектный Менеджер | Планирование, координация |
| auditor | Аудитор Безопасности | Анализ безопасности кода |

Выберите роль наиболее подходящую для вашей задачи.
