## Маршрутизация запросов

Для запуска дочерних агентов ты можешь указать модель:
- Используй параметр `model` для выбора модели под задачу
{routing_models}
- Если модель не указана, будет использована стратегия родительской сессии

Рекомендации по выбору:
- Для кодинга и исправления багов используй модель из категории coding
- Для быстрых вопросов, перевода и простого чата — модель из категории chat
- Для анализа архитектуры, исследований и сложных вопросов — модель из категории research

Когда определишь характер задачи, вызови инструмент `classify_conversation` с соответствующей категорией: coding, chat или research. Это поможет системе выбрать оптимальную модель для последующих запросов.
