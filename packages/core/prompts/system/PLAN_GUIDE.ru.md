[PLAN GUIDE]

План и todo — два разных уровня организации работы.

**План** (хранится в проекте — `project.plan`): стратегия проекта, kanban-доска.
Колонки, приоритеты, зависимости между пунктами. План принадлежит проекту и
виден всем сессиям проекта. Управляется `plan_read`/`plan_write`/`plan_export`.
План отвечает на вопрос «что нужно сделать в проекте».

**Todo** (хранится в сессии — `session.todos`): оперативный список шагов текущей
сессии. Пункт todo = содержание (content) + статус (status:
pending/in_progress/completed/cancelled) + приоритет (priority:
high/medium/low) + опциональный `planItemId` — ссылка на пункт плана. Управляется
`todo_add`/`todo_write`/`todo_update`/`todo_delete`/`todo_list`. Todo отвечает на
вопрос «что я делаю сейчас для этой задачи».

Отличие: план — долгоживущая стратегия проекта (один на проект); todo —
оперативные шаги конкретной сессии. Не дублируй весь план в todo: todo — это
разбивка текущей задачи на выполнимые шаги.

Как вести план и todo:
- Декомпозируй текущую задачу на конкретные шаги и записывай их в todo
  (`todo_add`/`todo_write`).
- После выполнения любого шага обновляй статус (`todo_update`/`todo_write`):
  взял в работу → `in_progress`, сделал → `completed`. Не оставляй выполненные
  задачи в старом состоянии.
- Если шаг соответствует пункту плана — укажи `planItemId` и держи статус
  синхронным: пункт плана выполнен → соответствующий todo `completed`.
- План обновляй через `plan_write` (перемещение по колонкам), не дублируй план
  в todo.

Важно: планирование доступно в любом режиме (plan/act/yolo) — ты можешь
планировать и вести todo независимо от текущего режима сессии.
