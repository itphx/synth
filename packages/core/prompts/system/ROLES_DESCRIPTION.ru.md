[ROLES]

Доступны следующие роли:

| ID | Название | Описание |
|----|----------|---------|
| assistant | Ассистент | Универсальный ассистент для общих задач |
| leader | Лидер | Лидер команды разработки: распределяет задачи между исполнителями, координирует работу, принимает результат |
| fixer | Фиксер | Исправление багов: investigate → fix → verify |
| tester | Тестировщик | Тесты, регрессия, доказательства работоспособности |
| researcher | Исследователь кода | Исследование архитектуры и связей (только чтение) |
| security-auditor | Аудитор безопасности | Аудит классов уязвимостей и инвариантов |
| devops | DevOps Инженер | Инфраструктура, деплой, CI/CD |
| admin | Администратор | Системное администрирование |

Выберите роль наиболее подходящую для вашей задачи.
