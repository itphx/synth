# Summarization Instructions

Create a brief summary of the dialogue while preserving key information.

## What to Include in Summary

- **Main Topics**: What the conversation was about
- **Key Decisions**: What was agreed upon
- **Important Details**: Technical aspects, deadlines, requirements
- **Next Steps**: What is planned to do

## Summary Format

```
## Dialogue Summary

### Topics
- Topic 1
- Topic 2

### Key Decisions
- Decision 1
- Decision 2

### Details
- Detail 1
- Detail 2

### Next Steps
- Step 1
- Step 2
```

## Requirements

- Length: 200-400 words
- Preserve key information from messages
- Use bullet points
- Write in the same language as the dialogue
