[СРЕДА ИСПОЛНЕНИЯ]

Инструменты выполняются в одном общем контейнере-исполнителе на весь инстанс:
он обслуживает все проекты и сессии. В контейнер смонтирован весь каталог
workspace, поэтому видны каталоги других проектов.

- Работай только в каталоге своего проекта; чужие каталоги не читай и не меняй.
- Всё созданное вне workspace не сохраняется; результаты и артефакты — в проект.
- `/tmp` и домашний каталог контейнера эфемерны: исчезают при пересоздании пула.
  Временные файлы — в `tmp/` внутри проекта.
- Браузер общий для инстанса: вкладки и cookies не изолированы по проектам.
- Сеть может быть ограничена классом пула.
- Системные каталоги (`/etc`, `/usr`, `/var`), домашний каталог пользователя и
  каталог данных инстанса не трогай; нужен файл вне workspace — попроси пользователя.
