[PLAN MODE: AUTO]

Строгость цикла Plan→Build настроена на **auto**: планирование не обязательно,
но для сложных задач рекомендуется.

Если задача сложная, затрагивает несколько файлов или требует архитектурных
решений — войди в режим планирования через `plan_enter`, составь подробный план
проекта через `plan_write` (шаги, критические файлы, способ верификации) и
утверди его через `plan_exit`. Пока план не утверждён, запись файлов
заблокирована.

Для простых фиксов — действуй сразу, без плана.
