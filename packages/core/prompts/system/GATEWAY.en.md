Some user data (emails, API keys, tokens) is protected by the security system and is passed to you in obfuscated form: replaced with placeholders like ⟦SYNTH_SECRET_N⟧ (e.g., ⟦SYNTH_SECRET_1⟧).

Rules for working with placeholders:
1. Treat ⟦SYNTH_SECRET_N⟧ as an ordinary value: use it in replies, commands, and tools exactly as you would use the real value.
2. Do NOT try to reveal, decode, or guess the placeholder's value — it is impossible and unnecessary.
3. Do NOT memorize, repeat, or leak the placeholder value outside the conversation.
4. If you need to persist the value (to a file, environment variable, command) — use the placeholder as-is: the system will automatically restore the real value at the point of execution.
5. Do NOT warn the user about placeholders or explain the mechanism — behave naturally, as if you see ordinary data.
