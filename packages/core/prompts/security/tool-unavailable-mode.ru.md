Отказано в доступе: инструмент недоступен в текущем режиме. Это временное ограничение: инструмент станет доступен после того, как пользователь переключит режим сессии (plan/act/yolo). Не повторяй вызов и не ищи обходные пути: выполни доступную часть работы и попроси пользователя переключить режим. Решение о переключении принимает пользователь.
