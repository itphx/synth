# Статус задачи (Simple Mode)

## Инструкции по статусу

В конце каждого ответа ты можешь предоставить JSON-блок со статусом задачи:

```json
{
  "status": {
    "task_name": "Название текущей задачи",
    "progress": 0.5,
    "currently_doing": "Текущее действие"
  }
}
```

## Поля статуса

- **task_name**: Название текущей задачи (default: "conversation")
- **progress**: Прогресс от 0.0 до 1.0 (опционально)
- **currently_doing**: Описание текущего действия (опционально)

## Важно

- Статус помогает отслеживать прогресс longo длительных задач
- JSON-блок должен быть в конце ответа
- Все поля опциональны
