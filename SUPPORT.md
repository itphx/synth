# Support

Need help with Synth? Here is where to look and where to ask.

## Documentation

The canonical user documentation lives on the portal:

- **Portal (RU by default, EN under `/en/`):** <https://docs.synth.itphx.ru/>
- Quick start: <https://docs.synth.itphx.ru/getting-started/quickstart/>
- Providers: <https://docs.synth.itphx.ru/getting-started/providers/>
- Hybrid mode: <https://docs.synth.itphx.ru/deploy/hybrid/>
- CLI: <https://docs.synth.itphx.ru/help/cli/>
- FAQ: <https://docs.synth.itphx.ru/help/faq/>

Developer documentation is in this repository — start with
[`README.md`](./README.md), [`docs/`](./docs/) and [`AGENTS.md`](./AGENTS.md).

## Questions and discussions

- **GitHub Issues** — bug reports and feature requests:
  <https://github.com/itphx/synth/issues>. Please use the issue templates.
- **Telegram channel** — announcements and community chat:
  <https://t.me/synth_dev>.

Before opening an issue, please search existing issues and check
[`docs/TROUBLESHOOTING.md`](./docs/TROUBLESHOOTING.md).

## Contributing

Want to send a change? See [CONTRIBUTING.md](./CONTRIBUTING.md). All participants
are expected to follow our [Code of Conduct](./CODE_OF_CONDUCT.md).

## Security

**Do not** report security issues through public issues. Follow
[SECURITY.md](./SECURITY.md).

## Financial support

Synth is self-hosted and open source. If you would like to support development,
see the support section of the landing page: <https://synth.itphx.ru/#support>.

## Commercial and enterprise

For self-hosted / enterprise deployment questions, contact us at
**admin@itphx.ru** or via Telegram at <https://t.me/synth_dev_admin>.
