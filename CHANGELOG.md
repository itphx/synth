# Changelog

All notable changes to Synth are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## About this file

This file is a short, human-maintained index. **Release notes are generated by
[`scripts/changelog.sh`](./scripts/changelog.sh)** — either from a prepared
description in [`docs/releases/<version>.md`](./docs/releases/) or automatically
from commits between the previous tag and `HEAD`. The generated notes are published
on:

- **GitVerse Releases:** <https://gitverse.ru/itphx/synth/releases>
- **GitHub Releases (mirror):** <https://github.com/itphx/synth/releases>

For the full history of released versions, refer to those Releases pages. Earlier
entries are not reproduced here.

## [0.10.1] — 2026-10-15

Small follow-up release on the `0.10.x` line.

### Changed

- Decomposition of god objects (ADR-095): large classes split into focused modules.
- Architecture documents split into ADR (accepted decisions) and PROP (proposals);
  see [docs/ARCH_DECISIONS.md](./docs/ARCH_DECISIONS.md).

### Fixed

- LLM provider fixes.
- Storage fixes.
